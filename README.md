## 📜 Description

Bring back full protection! **Black Exfil Revision** for *Single Player Tarkov* lets you equip compatible face shields on the Black Exfil helmet once again, just like in the old days.

## 📁 Installation

* Download the latest release
* Copy the `SPT_Runtime` folder into your SPT installation
* Start the game
